ATS-4

コンテストの集計を、自動で。

ログの受付から規約に沿った照合、得点計算、結果の公開まで。ALLJA1 コンテストや電通大コンテストをはじめ、多くのコンテストで使われています。

zLog Max

次のロガーが、来る。

コンテストロガー zLog を Rust で作り直した、macOS、Windows、Linux 対応の新しい版です。コンテストの規約も、ファイル形式も、ウィンドウも、機器も、すべてを部品として組み合わせます。

max.zlog.org GitHub

ZyLO

zLog を、自由に広げる。

zLog 令和版の公式プラグイン開発キット。Go 言語で書いたプラグインを、zLog のプラグインマネージャから簡単に導入できます。

スライド (PDF) GitHub

CW4ISR

モールスを、AI で読む。

AI を使ったモールス解読アプリ。受信帯域にいるすべての局を同時に解読し、ウォーターフォールと並べて表示します。
